# aws sagemaker basic model training

This Python script demonstrates a basic machine learning model training process using AWS SageMaker. It configures and launches an XGBoost training job, showcasing how to specify the algorithm image, execution role, instance type, and input data location for training.

## Language

`python`

## How to Run

1. Ensure you have AWS credentials configured.
2. Replace 'your-sagemaker-bucket/path/to/your/train.csv' with your actual S3 data path.
3. Replace 'your-sagemaker-bucket' with your S3 bucket name.
4. Run the script using: python main.py
